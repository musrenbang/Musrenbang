📲 Instal Aplikasi (Android / iPhone / PC)

Android/PC: menu ⋮ browser → Install App / Tambah ke Layar Utama.
iPhone: ketuk Bagikan ⎙ → Add to Home Screen. Aplikasi terbuka layar penuh & tetap bisa dibuka offline.

✨ Cara Menggunakan

1

Admin: buat akun / login, lalu input data survey lapangan lengkap dengan foto & titik koordinat.

2

Kelola: cari, filter, edit, dan export seluruh database ke Word / Excel / PDF.

3

Monitoring: pantau semua titik di peta interaktif beserta grafik laporan.

Menu Input — New Data Survey

Gunakan menu ini untuk menambah data survey lapangan. Mohon diperhatikan dengan seksama: ① semua kolom bertanda bintang (*) wajib diisi — data tidak dapat disimpan apabila masih ada yang kosong; ② tentukan titik koordinat minimal 2 titik (Awal dan Akhir) secara akurat melalui klik peta atau tombol Lokasi Saya; ③ lampirkan minimal 2 foto dokumentasi; ④ periksa kembali seluruh isian sebelum menekan Save. Terima kasih atas ketelitian Bapak/Ibu.

🗂️

Menu Data — Big Data Survey

Kelola seluruh database survey dengan mudah: gunakan kolom pencarian dan filter untuk menemukan data, klik No. ID Survey untuk melihat detail, serta manfaatkan tombol edit, hapus, dan export Word / Excel / PDF sesuai kebutuhan.
